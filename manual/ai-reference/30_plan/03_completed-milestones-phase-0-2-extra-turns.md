# 2026-09-28 追加ステップ・追加ターンの進行監査

サグメの追加アタック終了後にエンドへ進む不具合を起点に、登録済みの `grant_extra_steps`（BSTH10-X03 / BSLH01-X01）、`grant_extra_turn`（BSTH02-M01）、`skip_next_turn`（BSAZ01-C03）、通常進行・強制終了・遅延開始・保存状態を監査した。

## 修正

- 挿入前の続きと追加ステップの残りを状態に保存。終了時効果の待機中は予約を消費せず、同位置の重複追加・入れ子にも対応する。
- 効果によるアタック終了を共通ステップ遷移へ統合。追加アタックからコアへ戻り、開始時誘発・固定処理を実行する。ターン強制終了時は未実行のステップを破棄する。
- 連続する同名ステップでもステップ制限を更新し、ターン制限は維持。エンド後の追加ステップ中もターン期間を維持する。
- 通常／追加ターンの開始を `enterTurn` に統合し、開始時効果・デッキ切れ・回数初期化を共通化。
- 一般型追加ターンをターン末予約へ修正。所有者変更・連続取得・次ターンスキップでも本来の次プレイヤーを保持する。
- 中断型はターン内の予約・履歴・使用回数・中断元だけの継続効果を退避して復元。新しいターン番号の再利用を防止する。カード・コアの実移動は維持する。
