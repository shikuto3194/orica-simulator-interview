# Phase 7–8: 公開メディアのGit管理

親: [完了履歴索引](03_completed-milestones.md)

## 2026-09-19: 公開版の曲・タイトル背景欠落の修正

- Netlify公開版の素材一覧で背景0枚・曲0曲を確認。Git管理外だった背景45枚・曲260曲を、WebP品質88／AAC 128kbpsのM4Aへ変換し、圧縮版だけをGit管理する方式へ変更した。
- 元素材はローカルに保持。約1.88GBから約907MBへ削減し、約700MBのゼロ埋めを持つMP3も音楽部分を保持して変換。背景の解像度・顔位置、曲の長さ・チャンネル数を維持し、全音源の復号を検証した。
- 公開ビルドは登録作品の背景または音源が欠けると失敗する。dev・CI・Netlifyとも同じ圧縮素材を読み、通常のbuildに変換ツールは不要。再生成・差分検証は `pnpm bgm:prepare`。詳細は[公開用dist](../00_meta/public-build.md#タイトル背景bgm-の配備前提)。
- 旧公開版の空のBGM一覧が保存済みでも、最新一覧を再取得して逐次再生へ復帰する。利用者の保存データ削除や全曲の一括取得完了を要求しない。
- 公開ビルドとブラウザーで背景・曲名・曲送り・AAC復号・保存後のオフライン再起動を確認。GUI／RESTシナリオも通過。公開先への反映状況は[PC配備](../00_meta/local-pc-deployment.md)で管理する。
- 右下のNetlifyバッジはユーザーがサイト設定で無効化し、公開ページから消えたことを確認した。
