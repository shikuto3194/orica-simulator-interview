# 入力フォーム・デッキ保存の上限検証（2026-09-21）

- デッキの取込・ローカル保存・クラウド応答・保存・ルーム API を共通検証へ接続。巨大値、非整数、合計上限超過を展開前に拒否し、JSON ファイルには読込前の1 MiB制限を設けた。
- 表示名30文字、BSデッキ名100文字、メイン／トークン各1,000枚の保存上限をDBでも強制。直接更新・RPC迂回を防ぎ、既存のRLSと共有ACGデッキの動作を保持する。
- 検証は TypeScript の境界テスト、PGlite の実 migration、ブラウザーと REST の往復。文字列のエスケープ動作と絵文字の文字数も確認対象に含む。
- 仕様と検証入口: [入力検証](../00_meta/input-validation.md)。
