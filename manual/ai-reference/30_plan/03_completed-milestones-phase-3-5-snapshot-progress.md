# オンライン選択と宣言済み誘発の進行監査（2026-10-03）

## 観測と原因

提供された2件のsnapshotと、報告者の直前操作を照合した。

- `2026-10-02T15-09-03-907Z`: BSTH01-C21の攻撃ステップ終了を、合体中のBSGE01-R02から全コアを支払って使用。BSGE01-C05の残留/同行選択が開く。相手へ配送する状態では選択本体が隠されるため、JSONだけでは選択が消えたように見える。実際の不具合は、本人向け配送状態で両選択を解決した後も`pendingPromptLock`が残り、同じaction内の`advanceStep`が例外になることだった。
- `2026-10-03T00-58-18-586Z`: ディオスクリア転醒で手札のアルドノアドライブ2枚を宣言。1枚目の下置き・ドロー・コア追加の後、通常の転醒時効果と2枚目の即時効果が残る。通常効果はまだ選べないが、画面がキュー総数を順序選択数に数えて自動実行を停止し、宣言済み効果の手動ボタンも一律に隠していた。保存ルームの完全状態も読み取りで照合した。

## 共通処理の修正

- 配送用ロックは`applyLegalAction`の入口で操作主体を確認して消費する。実際のpendingは残し、既存の解決処理と終了ゲートが判定する。相手の秘匿選択中の合法手制限と、`advanceStep`を直接呼ぶ場合のロックは維持する。
- 自動解決では現在の合法手を持つキュー項目だけを数える。複数項目を選べるときは手動順序を維持する。宣言済み効果も前面と合法手の共通照合で手動ボタンを表示し、自動処理が使えない選択・対象指定の経路を残す。
- ブレイヴ残留/同行と旧snapshot互換のアタック継続選択に、既存の`modalsHidden`を配線する。非表示中もゲーム操作を許可せず、選択へ戻れるようにする。

- snapshot/棋譜読込とシナリオCE再構築の定義参照を、既存の裏面展開helperで統一。正当な転醒時効果を未登録として削除しない。デッキ構築用の表面一覧は維持する。

カード本文・DSL・裁定は変更していない。離脱確定は[離脱選択](../10_rules/04d_leave-choice-timing.md)、即時効果と後続誘発は[同時誘発](../10_rules/02b_declaration-timing-window-principle.md)の既存規則に従う。
