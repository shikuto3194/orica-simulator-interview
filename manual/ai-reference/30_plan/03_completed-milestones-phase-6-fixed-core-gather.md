# 固定コア移動の選択監査（2026-09-16）

## 監査条件

ユーザー指定: 移動元・置く数・置く場所がすべて固定なら、コアHUDで選択しない。
移動元を選ぶケースは対象外。効果そのものの「置ける」の発揮/辞退は維持する。

カード定義の `core_distribute` と `core_move` を構文解析で列挙し、固定の移動元・個数・
配置先を持つ定義と実行経路を確認した。全数指定と「好きなだけ」の上限表現を区別した。

| 分類 | 確認結果 |
| --- | --- |
| BSTS01-X02 煌臨時 | ライフ・ソウル以外の全通常コア→自身。唯一の修正対象 |
| BSTH09-X01 トラッシュ全コア→自身 | `core_move` の直接移動経路。HUD不要の既存挙動を維持 |
| BSAZ02-C06 自身全コア→リザーブ | `core_move` の直接移動経路。HUD不要の既存挙動を維持 |
| ボイド→自身/リザーブ等の固定数 | `core_move` の直接移動経路。追加修正なし |
| BSTH001-M01 指定Lvまでボイドから配置 | `core_set_to_level` の直接移動経路。追加修正なし |
| BSSG01-C03/C04/M01/M02、BSSL01-CX01、BSTH09-X02 | 自身への配置でも「好きなだけ」で個数・移動元を選ぶため対象外 |
| BSTH01-X04、BSAZ01-C12、BSAZ02-C07 | 分身への任意コア配置。移動元・配分を選ぶため対象外 |
| BSTH02.7-TX01(A)、転醒後の最低Lv補充 | 移動元を選ぶため対象外 |
| BSDB01-C08、BSRK01-C07、BSTH11-X02等 | 配置先・配分を選ぶため対象外 |
| 通常/ソウルの一部を選んで移動 | 物理コアの選択が残るため、全コア移動と混同しない |

## 修正

- `non_life_normal_self` の全数・単一配置先は、共通の移動元列挙と
  `moveNormalCores` を使い、配分pendingを生成せずに処理する。
- 実配置数を後続の「3個につき1体、最大5体」に引き継ぐ。
- 独自管理コアは要求対象外。その他の移動禁止コアは全数達成判定から除外しない。
  移動できたコアは巻き戻さず、未達時は「そうしたとき」の後続だけ不発にする。
  根拠: ユーザー指定（信頼度C）および
  [既存の完全達成規則](../10_rules/03c1_effect-connectors-and-completion.md)。
- `core-movability.ts` の同じ列挙関数を、回収と全数達成判定の両方で使う。
- カード番号で分岐するハンドラ、GUI側の自動クリック、公開型の追加は行っていない。
