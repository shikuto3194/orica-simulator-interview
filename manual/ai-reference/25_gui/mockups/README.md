# ホーム画面のレビュー

本体への実装済み。現在の外観・挙動は[実装仕様](../18_home-lobby.md)とアプリを参照。
このHTMLは検討時の案を保存したもの。以下のサンプル配信や赤いタブ選択線は本体の仕様ではない。

[`home-lobby.html`](home-lobby.html) をブラウザーで開く。
背景の暗さ調整、中央の全身アバター20体の切替、メッセージ・運営通知の
サンプルパネルを操作できる。通信やメッセージの実送信は行わない。

上部は現行の `DeckBuilder.tsx` と同じ「🏠 / カード検索 / 作成中デッキ / 保存デッキ / QA」。
`deck-builder-layout.css` の幅配分（1:2.5:2.5:2.5:1）と、赤い選択ラインを引き継ぐ。
メッセージ・運営通知・設定はホーム内の右上に配置。
タブを押すと選択状態と内容領域が切り替わるが、ホーム以外は案内のみを表示する。

曲プレイヤーは既存 `BgmControls.tsx` の小型サイズ（余白6px/12px、最大幅80vw/520px）を
基準に、右下へ配置。作品名・曲名の2段表示と金色のアイコンは維持する。
手動の背景切り替えは設けない。

全身画像は [`images/avater/fullbody`](../../../../images/avater/fullbody/README.md) を参照。
背景画像は既存のタイトル素材から作成したレビュー用縮小版。
SVGアイコンはLucide（[ライセンス](assets/lucide-license.txt)）を使用し、外部通信なしで表示する。

このHTMLはホーム画面を検討するためのモックアップであり、本番アプリの画面ではない。
