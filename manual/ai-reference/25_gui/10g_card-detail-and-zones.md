# 視点切替・カード詳細・除外閲覧

親索引: [シチュエーションテスト](10_scenario-test-reference.md)。

## トークン詳細・除外閲覧

`?scenario=card-detail-zones` は両プレイヤーにトークン参照元、トラッシュ、除外カードを配置する。`empty=1` は除外0枚、`emptyTrash=1` はトラッシュ0枚。

- トラッシュの画面端側に画像なしの「除外」。自分側は右に「＞・除・外・＞」、相手側は左に「＜・除・外・＜」を縦に並べる。高さはトラッシュに揃え、文字を安全領域内に残して外側の枠を画面端で見切れさせる。ノッチ用の左右余白がある場合は、その分だけ外側の枠を延ばす。トラッシュはデッキと同じ中央位置を保つ。既存ゾーンブラウズからカード詳細を開ける。
- トラッシュと同じ段の余白からも、画面内側へ横にスワイプすると除外を開く（自分側は左向き、相手側は右向き）。40px以上の横移動で判定し、通常タップはトラッシュ閲覧・コア選択を維持する。縦方向・逆方向・複数指・キャンセルでは開かず、スワイプ後のクリックも重複させない。
- 「トークンを見る」で関連トークンを巡回し、元カードへ戻れる。トークン閲覧時は元カードの現在の色・シンボル・コア等を重ねない。
- GUI: `e2e/scenario-card-detail-zones.spec.ts`。1280×800、844×390、780×360の配置、空トラッシュ・左右の安全領域・両者・除外0枚・詳細・複数トークンを確認。

- スワイプGUI: `e2e/scenario-removed-zone-swipe.spec.ts`。実タッチとマウス、左右、余白・空トラッシュ・視点反転・安全領域、タップ維持、誤操作とキャンセルを確認。

## BSLH01-C09のデッキ下戻し

同シナリオの `mode=search` はC09の召喚時効果を開始する。`owner=bob` でBob REST、`noMatch=1` で取得候補なし。

GUI/REST: `e2e/scenario-bslh01-c09-search.spec.ts`。カウント増加、取得候補・0枚確定、残りの順番確定を経て、未公開カードより下に戻り、トラッシュ・公開中に残らないことを確認する。

## 視点切替 (`?viewer=`)

- `?viewer=alice|bob` (省略時 alice) で自分/相手を切替。`?scenario=` 直開き・観戦・スナップショット読み込みすべてで尊重 (`App.getViewerFromUrl`)。スナップショットを bob 視点で見るには URL に `?viewer=bob` を付けて読み込む。
- **隠匿マスクは表示層で自動適用**: シナリオ/スナップショットはサーバ sanitize 非経由のため、`BattleScreen` が `sanitizeStateForViewer(state, viewingPlayer)` で表示用 state を算出。engine/legal-action/auto-play は full state を使う。各 build で `_hidden_card_` 化不要（既存手動マスクは互換残置）。
