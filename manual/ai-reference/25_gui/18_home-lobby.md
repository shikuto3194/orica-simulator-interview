# 幻想符のホーム・共通外観

実装: `apps/playground-web/src/components/HomeLobby.tsx`、`home-lobby.css`、`nonbattle-theme.css`、`app-theme.css`。
検討時の[モックアップ](mockups/README.md)を本体へ組み込んだ仕様。現在の正源は本体。

## 表示・遷移

- タイトル・ホーム・ブラウザー題名・PWA名を「幻想符」に統一。
- 題字はしっぽり明朝 Medium。Google Fonts の「幻想符」3字サブセットをローカル同梱する。
  [配布元](https://github.com/google/fonts/tree/main/ofl/shipporimincho)、SIL OFL 1.1。
  ライセンスは `apps/playground-web/public/fonts-license.txt` に同梱。題字は外部通信に依存しない。
- タイトルは淡い金色の細線、余白、明朝の字間で構成。文字の縁取り・影は使わず、背景側の暗幕だけで可読性を確保する。ログイン・素材取得・開始操作は従来どおり。
- 上部5タブの順序・幅配分・文言は維持。選択線、入力、パネルを金色と暗い半透明面で統一。
- カード検索・作成中デッキ・保存デッキ・QAは明朝の見出しと控えめな太さの操作文字、淡い金色の見出し・件数、暖色寄りの補助文字に統一。枚数バッジも葡萄色／茶金色に揃える。タイトル・ホーム・バトルの文字設定には適用しない。
- 作成中デッキの保存・共有・クリアは個々のボタンだけに背景を付け、操作領域全体は透明にする。保存デッキの共有中メッセージは表示せず、取得エラーは引き続き表示する。
- 横画面のデッキ詳細は閉じるボタン用の上部帯を設けず、カードを上端付近から表示する。×ボタンだけに不透明度18%の背景を付け、枚数バッジより手前で操作できるようにする。
- ホームは登録アバターの全身を中央へ `object-fit: contain` で表示。画像のトリミング・再生成はしない。
  画像は[全身アバター記録](../../../images/avater/fullbody/README.md)を参照。
- 表示名・アバター・保存デッキ件数は既存データを使用。アバター変更はホーム内の変更モードで行う。
- 「アバター変更」で全身絵の左右スワイプ・矢印キー操作を有効にし、下部に「決定」「キャラを選択」「キャンセル」を表示。「キャラを選択」を押したときだけアイコン列を展開する。
- 全身絵・名前・二つ名とアイコン列は双方向に同期し、選択アイコンを中央へ寄せる。アイコン列もスワイプできる。変更中のジェスチャーはタブ切替へ伝播させない。
- 候補の選択はローカルプレビュー。「決定」だけで自分の `avatar_id` を保存し、共通プロフィールへ更新行を反映する。保存中は操作を止め、失敗時は候補を保持して再試行可能。キャンセルは保存済みアバターへ戻す。
- マイページにはアバター編集を置かず、表示名、アカウント設定、運営メニュー（管理者のみ）・ログアウトの順に配置する。表示名は `display_name` だけを保存し、アバターを上書きしない。メール／パスワードのフォームは各「変更」で開く。
- メッセージは[ルーム招待](20_room-invitations.md)の受信一覧へ遷移。未読がある間は右上の赤い丸バッジに件数を表示し、0件で消す（100件以上はバッジだけ `99+` に省略）。運営通知は[日次更新のお知らせ](23_operation-notices.md)へ遷移し、別の未読バッジを表示する。
- 「1人バトル」「対戦ルーム」「作成中デッキ」「保存デッキ」は既存機能へ遷移。
  マイページ・1人バトル設定・対戦ルームの戻り先はホーム。「タイトルに戻る」は別操作として残す。
- バトル・観戦・棋譜の「・・・」メニューは「ホームへ」でホームに戻る。通常のルーム退出通知は維持し、シナリオ等のURLパラメータも初期化する。
- 対戦ルームの入口では、ログイン中の本人が参加済みで未決着のルームを一覧表示。「戻る」で元の席・登録済みデッキ・盤面へ復帰する。URLパラメータは不要。「ルームを作成」とID・QRからの新規参加も残す。一覧表示は接続扱いにせず、[通常の削除期限](../00_meta/room-retention.md)を維持。削除済みのルームを選んだ場合は一覧を再取得する。
- 曲プレイヤーは従来の小型サイズ・機能を維持して作品名／曲名を2段表示。背景切り替え操作は設けない。
- 非バトル画面のタイトル以外の背景画像はブラー2px・暗幕32%。タブ内の操作面には読みやすい半透明パネルを重ねる。
- 背景画像はタイトルと同じ `cover`・位置計算で表示し、追加拡大はしない。ぼかしは暗幕の `backdrop-filter` で適用し、画面端の透けと遷移時の位置ずれを防ぐ。
- ホーム・カード検索・作成中デッキ・保存デッキ・QAは共通背景だけでぼかしと暗さを揃える。タブ領域全体への追加の暗幕・ぼかしは重ねず、入力欄やカードなど個々の操作面は半透明パネルを維持する。タイトルはぼかしなし。

## 画面サイズと適用境界

- 横画面は「プロフィール／全身／操作」の3列。高さ600px以下では余白・補助文を減らし、キャラ全身と操作を収める。
- 縦画面はプロフィール→全身→操作の1列。ホーム内のスクロールで下部操作に到達できる。
- 横画面のホームはプレイヤーの実測位置と表示項目の横方向の重なりを確認し、必要な下余白だけ確保。アバターは通常表示・変更中とも中央列全体ではなく、二つ名・名前・各ボタン等の実際の幅と下端で判定し、空いている画面下部まで使う。曲名変更・プレイヤー展開・アバター変更・画面回転で再計測し、プレイヤーの位置・大きさ・操作は維持する。
- アバター変更中は左右のホーム項目を隠して中央列を全幅に広げる。横画面の下余白は全幅の列ではなく、個々の下部ボタン・選択列・メッセージとプレイヤーの重なりから算出し、不要な空白を作らない。短い横画面では補助見出しを省略し、全身絵・選択列・決定操作を収める。
- 縦画面のホームと他の非バトル画面では、曲プレイヤーの実測高さに応じた末尾余白を確保。プレイヤー展開時も横にはみ出さない。
- 他タブは従来の検索・結果の左右分割、仮想スクロール、カード枚数操作を維持。
- 共通配色はタイトル・ホーム・全タブ・ルーム・バトル・観戦・リプレイと全ボタンに適用。body直下のポータルメニューも対象。
- `.gensou-shell` は非バトル画面の配置だけを担う。バトル・観戦・リプレイにホーム専用レイアウト／背景画像／浮動プレイヤーは追加しない。
- `app-theme.css` は塗りだけを変更。寸法、余白、文字のメトリクス、配置、重なり、ポインター判定、既存の動作は変更しない。アクションバーと下端操作のコンテナは背景・影なし、従来のクリック透過を維持する。
- 元の透明度を保持する。バトルの通常アクションボタンは不透明度42%（ホバー55%）、下端操作は20%（同35%）。元が透明なカードアクション／効果選択コンテナに新しいパネルを足さない。各部の透け方を単一の不透明な面に置き換えない。
- ボタンは主要操作も周囲と同じ暗い半透明面に揃え、主要操作・選択中は淡い金色の枠で区別。メッセージ行・招待候補・文字ボタン・通知スイッチの背景は透明に保つ。ホバーは控えめな明暗差と細い内枠、押下は浅い内影で区別する。キーボードフォーカスは2px輪郭を残し、無効状態はホバー／押下で強調しない。
- インライン配色のボタンも共通の状態表示へ接続。確定・削除の意味は `ui-primary` / `ui-danger`、選択状態は既存クラスまたは `aria-pressed` / `aria-checked` で表す。カード属性・コア・攻撃／対象選択の識別色は維持する。
- 公開ビルドには `AVATARS` に登録した20体のWebPだけを追加。制作記録・元PNG・レビューHTMLは公開対象外。
