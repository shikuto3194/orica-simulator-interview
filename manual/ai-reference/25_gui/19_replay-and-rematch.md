# 棋譜の保存・再生と再戦

## 導線

- 勝敗画面の「選択済みデッキでもう一度」は、両者のデッキ全枚数を維持して再戦する。ランダムで開始した対戦も最初に生成したデッキを保持し、山札の順序と対戦前の選択は初期化する。
- 1人バトルは画面内の選択状態も初期化する。復元した盤面では元のカード定義からデッキを復元する。40枚未満の検証盤面では既存のランダムデッキ補完を使う。
- ルーム対戦は登録済みデッキからサーバーで初期化し、CAS・既存の棋譜checkpoint・SSEを通して双方へ反映する。再戦要求は共通同期hookの最新受信versionを使い、相手による終局・再接続にも対応する。終局前、部外者、古いversionの要求は拒否する。
- 「棋譜保存」は、その対戦画面を開いてから記録した盤面をファイルへ保存する。再接続で開き直した場合は、その時点からの記録になる。ルームでは受信した権威状態のみを記録し、未確定の操作プレビューや相手の未公開情報は追加しない。
- ホームの「棋譜・盤面の読み込み」から、開発版・公開版ともに棋譜を読み込める。

## ルーム対戦のリセット

- メニューの「リセット」は相手へ申請を送る。相手が「承認」すると、勝敗後の「選択済みデッキでもう一度」と同じサーバー処理で登録済みデッキからpregameへ戻る。
- 各ゲーム、各プレイヤー1回だけ申請できる。申請時に権利を消費し、「承認しない」でも戻さない。使用済み・申請待ち・送信中・終局後はボタンを無効化し、既存ボタン同様に薄く表示する。未応答でも対戦操作は続けられる。
- 承認と終局後の再戦で双方の権利を戻す。状態とゲーム番号はルームに保存し、再接続でも権利を維持する。新ゲームでは画面内選択、pregame表示、棋譜記録も初期化する。
- `/reset-request` / `/reset-response` は参加者認証・version照合・mutation ID・CAS/SSEを利用する。申請者自身の応答、部外者、古いversion、重複申請を拒否する。
- `room-rematch.test.ts` / `battle-replay-reset.test.ts` と `e2e/room-reset.spec.ts` で、相手応答・拒否後の制限・再接続・デッキ維持・pregameへの復帰を検証する。

## 形式と表示

- 既存のJSON / JSONL / gzip、および `orica-replay-delta-v1` を利用する。保存ファイルは `orica-replay-*.jsonl.gz`、gzip非対応環境ではJSONL。録画用の座標・クリック履歴・追加フレーム情報は保存しない。
- 共通codecの正源は `packages/replay-codec/replay-delta.mjs`。CLIの旧importは再公開で互換性を保つ。
- 保存済みの `actionId` / `actionKind` / `choiceId` / 操作者と、前後のカード・コア・ステップの差分から操作を簡易再現する。
- 再生中は操作元から対象へカーソルを動かし、結果を既存の対人バトル画面で表示する。実際のマウス軌跡の復元ではなく、記録から推定できる位置だけを使う。盤面上に再生専用の説明文・疑似ボタン・対象一覧・強調枠・終端字幕を重ねない。
- カーソルの尻尾内に、現在の視点に対する「自」「相」を埋め込む。既存の合法手に一致する操作は対人戦のアクションバーを表示し、実ボタンへの移動と既存の押下表現を使う。
- 保存済みの `preGame.jankenHands`・ラウンド・勝者・先後指定から、対人戦と共通のじゃんけん画面、勝敗、先後選択を再生する。両者の手が同時記録されていれば両カーソルを描く。記録にない手は生成せず、契約・マリガンも保存状態を表示する。
- モーション・ステップ通知・公開情報通知・効果キューは対人バトルと同じコンポーネントを使う。保存済みの盤面・公開情報で表現し、再生向け通知や棋譜情報を追加しない。既存の再生プレイヤーの操作・配置・再生間隔は維持する。
- 盤面は手順ごとに再マウントせず、既存の移動・状態変化の演出を継続する。前後移動・シークは直接指定位置へ移動する。速度変更・一時停止・視点切替・ホームへの復帰を維持する。
- 再生盤面の切替時は、前の盤面で開いた対象選択・コア操作・確認・閲覧の一時状態を破棄し、切替先の選択待ちから表示を再構築する。同じ種類の選択が連続する場合や、同じ選択待ちIDが複数の記録に残る場合も更新する。
- 再生から対戦APIへ変更を送らない。終端では既存プレイヤーを停止して盤面を残し、棋譜上の終局で再戦処理を呼ばない。

## 実装・検証

- `BattleScreen.tsx` / `GameResultOverlay.tsx`: 再戦、記録、保存。
- `battleReplay.ts`: 盤面列の差分保存。同一状態の重複除外と再戦時の記録初期化。
- `replayViewer.ts` / `ReplayViewer.tsx` / `replayPresentation.ts` / `ReplayGestureOverlay.tsx` / `preGamePresentation.ts`: 読み込み、再生、表示専用の操作推定。対人戦とpregameの表示部分を共有し、再生時は操作を送信しない。
- `battle-replay.test.ts` / `room-rematch.test.ts`: 保存復元、盤面からの表示推定、登録デッキ・認可・versionの検証。
- `e2e/replay-viewer.spec.ts` / `e2e/public-build.spec.ts`: 保存→読み込み、再戦、操作演出、公開版の到達性、REST状態と再生の分離。
- `e2e/room-rematch.spec.ts`: 相手による終局のSSE受信・終局済みルームへの再接続後にGUIから再戦。
