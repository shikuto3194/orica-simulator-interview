- 本文: `packages/card-data/raw/by-pack/BSDB01.js`、`packages/card-data/src/cards/BSDB01.ts`。独自カードサイトの取得済みデータ（信頼度C）。公開元は [独自カードサイト](https://dancing-pixie-db5cc3.netlify.app/)。今回のWeb再取得は失敗したため、取得済み原文と画像を使用した。
- OC: rawの `ocBoost` と `images/BSDB01-TX01(A).png` などのカード画像。TX01(A)の画像・OC欄は **OC10+ / BP+9000**。rawの効果本文にあるOC12表記は画像と矛盾するため、カード定義の見出しを10へ修正した。Lv2本文は「カウント10以上」のアタック中効果であり、アタック時の誘発やOC中見出しに読み替えない。
- OCの基本処理: [公式エターナルBS60 FAQ](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=BS60)、ミラー `external-qa-official/BS60.md`（信頼度A）。指定カウント以上ではOC欄のBPを加算する。これは印字BPの計算であり、効果無効で消える継続効果として表現しない。
- 部分解決・空撃ち: 公式Q26241（`external-qa-official/SD01.md`）と [03b](../10_rules/03b_resolution-and-interrupts.md)。固定数の破壊は対価でなければ可能な限り実行し、対象数不足を発動条件にしない（A）。任意破壊も同じで、対価の全数要求は別に維持する。
- X01: `external-qa/qaData.js` **qa-017** は美鈴がフィールドに残るケースでも破壊後のライフ処理を認める。破壊イベントの派生反応を解決した後に条件を判定する既存 `after_triggers` を維持する（独自Q&A、A）。CX01の破壊発揮監視もこの派生解決に先に参加させる。
- C07: `external-qa/errataData.js` **id: 013** の「同名ターン1回」は既存DSLで対応済み。今回も維持する。
- 解釈一般: [03c](../10_rules/03c_effect-text-interpretation.md)、[03e](../10_rules/03e_effect-duration-and-repeat-scope.md)、[08a](../10_rules/08a_advent-rebirth-contract.md)。同じ本文の「その後」は単一効果の手順、個体ターン1回と明記された同名制限は区別する。

## C06の条件範囲（確認済み）

原文の「孫悟空がいるとき」はカウント増加文中にある。続く「さらに、…1枚ドローするか、…かめはめ波…を手札に戻せる」まで同条件を要求するかは独自Q&Aから確定できなかった。

2026-09-13、ユーザーが「ドロー／回収にも孫悟空が必要」と回答した（信頼度C、ユーザー確認）。魂状態を含む自分の孫悟空を要求する既存DSLを維持し、孫悟空不在ではドローも回収も発揮しない回帰を追加した。`needs-ruling.jsonl` の `BSDB01-C06-further-condition` は解決済みとし、[03b](../10_rules/03b_resolution-and-interrupts.md) にカード固有裁定を記録する。
