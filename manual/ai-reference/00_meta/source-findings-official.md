## 更新ルール

- 公式寄りの追加調査は、まずこの索引から既存の分割先を選んで追記する。
- 主題がさらに割れる場合は、新しい `source-findings-official-*.md` を追加し、この索引から辿れるようにする。
- 置き場を変えたときは、[source-map.md](./source-map.md) と入口 README の導線も同ターンで更新する。
