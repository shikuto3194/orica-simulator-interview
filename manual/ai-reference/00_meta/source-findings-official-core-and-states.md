### 5. コア資源とソウルコア

- `基本ルール` の検索スニペットから以下を補強した。
  - 初期ライフはボイドから 5 コア
  - 初期リザーブは 4 コア
  - その 4 コアは `ソウルコア1 + 通常3` または `通常4`
- `ルールQ&A` の検索スニペットから以下を補強した。
  - Q515: ソウルコアはゲーム中に 1 個だけ持てる特殊コア
  - Q516: ソウルコアは必須ではなく、使わないなら通常コア 1 個へ置き換えて開始できる
  - Q517: ソウルコアは通常コアのようにスピリットへ置いたり支払いへ使える
  - Q519: generic な `コア1個をボイドに置く` / `コア1個をライフに置く` ではソウルコアは移動できない
  - Q520: 通常の「コアの移動」で、ソウルコアと通常コアの入れ替えができる
  - Q521: `コア2個をボイドに置く` 効果を `ソウル1 + 通常1` に受けても、ソウルコアはボイドへ行かず、通常コアだけがボイドへ行く
  - Q530: generic な `創界神ネクサスにコアを置く` でもソウルコアは移動できない
- `神皇` 系カードの検索スニペットから以下も補強した。
  - 明示的に `[ソウルコア]を自分のライフに置く` 効果は存在する
  - したがって、Q519 は「ライフへ一切置けない」ではなく「generic な `コア1個をライフに置く` では移動できない」と読むべき
- `封印` ページの検索スニペットからも以下を補強した。
  - `《封印》` で `このスピリットの[ソウルコア]を自分のライフに置ける`
  - `《封印》` で `自分のリザーブの[ソウルコア]を自分のライフに置ける`
  - よって、`[ソウルコア]をライフに置く` explicit 例外は神皇個別カードに留まらず、キーワード運用上も重要
- `自分のライフを参照` 系カードの検索スニペットから以下も補強した。
  - 明示的に `自分の[ソウルコア]を創界神ネクサスの「契約神オメテオトル」に置く` 効果は存在する
  - したがって、創界神ネクサスについても「generic では不可だが、explicit 例外はあり得る」と読むのが妥当
- `ルールQ&A` と `創界神ネクサス` 系カードの検索スニペットから以下も補強した。
  - Q981: `〖ソウルドライブ〗` はソウルコアをゲームから除外することで発揮する
  - Q982: 除外したソウルコアはボイド/ライフ/リザーブ/フィールド/トラッシュと混ざらない別の場所に置く
  - したがって、`除外` は `void` と同一視してはいけない
- ただし、現時点で確認できた explicit 例外はまず `ライフ` であり、
  - `ボイド`
  - その他の禁止先
  にまで「明示なら常に可」と一般化できるだけの根拠はまだ不足している
- `相手のライフを減らす` 系カードの検索スニペットから以下を補強した。
  - ライフ減少は「ライフのコア 1 個をリザーブに置く」という表現で扱うのが自然
- `ルールQ&A` の検索スニペットから以下も補強した。
  - Q99-Q103: リフレッシュステップでトラッシュのコアすべてをリザーブへ戻す
  - Q100: 召喚/配置/使用に使ったコアはトラッシュへ置かれる
  - Q258: 相手のカードやコアは、置き先に自分側が明記されない限り自分側へは移動しない
- `カードのコスト及びその支払いについて` の検索スニペットから以下も補強した。
  - カード提示時点で支払いコストが決定する
  - 軽減に使った盤面が支払いで消えても、軽減は有効
  - 自分のソウルコアを移動するとき、指定がなければライフからも使える例がある
- `カード効果：トラッシュから手札にカードを回収する` や `カード効果：コアの移動を制限する` の検索スニペットから
  - トラッシュのソウルコア
  - リザーブのソウルコア
  がカードテキスト上の参照対象になることを補強した。
- `カード効果：自分のライフを参照` と `カード効果：相手のライフを減らす` の検索スニペットから
  - `自分のライフのコア1個をこのスピリットに置く`
  - `相手のライフのコア1個を相手のリザーブに置く`
  - `相手のライフのコア2個を相手のトラッシュ/ボイドに置く`
  - `自分のトラッシュの[ソウルコア]以外のコア1個を自分のライフに置く`
  という実例を補強した。
- これと Q519 / Q520 を合わせると、generic な `ライフのコア1個をリザーブ / フィールド / トラッシュに置く` で、行き先がソウルコアの通常移動可能先かつ `[ソウルコア]以外` 制限がない場合は、ライフの持ち主が通常コアかソウルコアかを選ぶ、という整理がかなり有力である。
  - ただしこれは複数ソースからの実装上の推論であり、単独の明示 Q&A 本文ではまだ確認できていないため、信頼度は `C` として扱う。
- これにより、カード本体移動とコア移動を別処理にする必要性がかなり明確になった。

### 6. 魂状態と待機状態

- `仮面ライダーW サイクロンジョーカー ［3］` の Q27442 から以下を補強した。
  - `魂状態` は「魂状態にできるルールや効果で、フィールドに置かれた契約カード」のこと
  - この状態ではスピリットなどではないため、
    - コアを置く
    - アタックする
    - ブロックする
    - シンボルで軽減する
    ことができない
  - Lv のある効果は発揮できないが、`〖魂状態〗` と書かれた効果は Lv に関係なく発揮する
- `カード効果：フィールドを離れるとき` と Q207 から以下を補強した。
  - `待機状態` は、破壊 / 消滅 / バウンスなどでフィールドを離れることが確定した段階の途中状態
  - `手札に戻す。この効果で戻した〜` のような省略テキストでは、「戻した〜」以降は手札に戻す待機状態になってから解決する
  - したがって、`待機状態` は custom 専用語ではなく、既存の `pendingLeaveKind` 系で受ける official leave-field model として扱ってよい

### 2026-03-23 再調査での追加補強

#### 5b. ソウルコアの追加裏取り

- `batspi.com/index.php?cmd=read&page=ソウルコア` の本文 (新規ソース、信頼度 A) から以下を確認した。
  - **移動禁止先の確定**: 「ライフ/ボイド/創界神/創界石には移動する事が出来ない」の4箇所が明示。従来は Q530 で創界神のみ言及していたが、**創界石**も禁止先として本文レベルで確認できた。
  - **相手効果時の持ち主選択権**: 「相手効果でコアが移動する際、ソウルコアを含めるかは持ち主が選択可能」。実装上、相手効果によるコア移動 UI でソウルコア選択の分岐が必要。
  - **自己消滅を伴う効果発揮不可**: 「ソウルコアをスピリット/アルティメット上から移動させる効果により、その効果を発揮したスピリット/アルティメット自身が消滅してしまう場合はその効果の発揮自体ができない」。
  - **初期配置**: 「ゲームスタート時、通常のコア3個とソウルコア1個をリザーブに置いてスタート」。
  - **メインステップの交換**: 「メインステップでスピリット/アルティメット2体の通常のコア1個とソウルコア1個を交換することができる」。

#### 5c. 封印の追加裏取り

- `封印` ページの本文 (信頼度 B → A に昇格) から以下を新規確認した。
  - **ライフにソウルコアのみの場合のボイド送り不可**: 「ライフにソウルコアしかないとき、ライフのコアをボイドに置く効果が発揮した場合、ソウルコアはコアを対象にした効果でボイドに置けないため、ライフは減らない」。open-questions P0 のソウルコア例外移動ルールに関連する重要な裁定。
  - **派生封印9種の完全リスト**: 《神速封印》《星座封印》《バースト封印》《超封印》《煌封印》《輝石封印》《謎封印》《天空封印》《月光封印》。すべて「封印行為」としてバースト条件の「《封印》後」を満たす。
  - **ソウルコア1個しか置かれていないスピリットからの封印不可**: 自身を消滅させながらの《封印》発揮はできない (ソウルコアページの自己消滅制限と整合)。

#### 5d. 強化の裏取り

- `強化` ページの本文 (信頼度 A 確認) から以下を新規確認した。
  - **数値0には適用されない**: 「数値が0の場合は効果が適用されない」。実装上、強化適用時のゼロチェックが必要。
  - **アルティメット対象外**: ルール改定により「アルティメット以外」という限定が追加されている。
  - **最終値参照**: 紫/緑/白/青の【強化】は、カードの効果に書かれた数値ではなく、実際に効果を解決する時の最終的な数値にかかる。

#### 6b. 消滅の追加裏取り

- `消滅について` ページの本文 (新規ソース、信頼度 A) から以下を新規確認した。
  - **Lv非依存キーワードは消滅状態でも失われない**: 「【チーム】など、Lvに関わらず所持しているキーワード能力の記述は消滅状態でも失われない」。実装上、消滅時の「全効果を失う」処理で Lv 非依存キーワードを除外する必要がある。
  - **待機状態のシンボルでは軽減不可**〔⚠ 2026-03-23 時点・**Ver.17.0(2026-04-11 適用)前の旧裁定**。現行は逆で「待機状態になったスピリットは参照でき、そのシンボルでコストの軽減もできる」(公式 Ver.17.0 改訂 `…/news/2026/rule-manual-eternal17-revised.php` で逐語確認)。正源は [10_rules/04_state-based-rules.md](../10_rules/04_state-based-rules.md)〕: 破壊/消滅/バウンスを問わず、待機状態に入ったスピリットのシンボルは軽減に使えない (ルール更新により統一)。
  - **コスト支払い消滅のトラッシュ遅延**: 「コストの支払いで消滅したカードは、そのコストの元となった効果の派生効果の全ての処理が終わるまではトラッシュに置かれない」。
  - **ネクサスの消滅**: 基本的に最低Lvコスト0で消滅しないが、Lvコストを増やされた場合はスピリット/アルティメット同様に消滅する。
  - **相手による消滅の判定**: 「相手のコア除去効果で最低Lvコスト未満になったとき」は相手による消滅。「相手の効果でLvコストが変更されている状態で自分がコアを動かして最低Lvコスト未満になった場合は相手による消滅とはならない」。

#### 6c. 魂状態の追加裏取り

- `魂状態` ページの本文 (新規ソース、信頼度 A) から以下を新規確認した。
  - **魂状態化時のコア移動先**: 「契約カードが相手によってフィールドを離れる際、魂状態のカードとしてフィールドに置くことを選べる。このとき、カード上のコアはすべてリザーブに移動する」。
  - **対象制限の明確化**: 「自身が発揮する効果以外では、魂状態を対象とした効果でしか対象に取られず参照もできない」。
  - **通常召喚不可**: 「通常の召喚はできず、魂状態のカードを召喚する効果でのみ召喚可能」。
