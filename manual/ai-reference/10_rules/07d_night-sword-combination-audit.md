# 夜空の剣: 合体効果の加算と組み合わせ監査

調査・適用日: 2026-09-10。対象: BSSA01-転醒X01(B)【武装完全支配術】。

## 根拠と採用範囲

- **A（本文確認）**: 独自カード本文のローカル一次資料 `external-qa/cardData.js` の夜空の剣。合体条件はC2以上・コスト7以上。合体中のコア除去数と相手ライフ減少数を各+1する。専用Q&A/errataはローカルミラーに見つからなかった。
- **A（公式エターナル）**: [ブレイヴのルール](https://www.battlespirits.com/rule/official-rule-manual-eternal/page09.html) の合体スピリットの扱い。[CB32 Q28062](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=CB32) と [コアシステム](06_core-system.md) により、ライフ・リザーブ・カウント・自分フィールドだけの移動はコア除去とは区別する。
- **A（公式Q&Aミラー）**: `external-qa-official/BS38.md` Q25487。対象選択のタイミングが異なる除去は、それぞれに加算する。
- **C（ユーザー明示裁定、実装採用）**: 2026-09-10の依頼で、ホスト・合体ブレイヴのすべての除去/ライフ減少イベントへ適用すること、同時に「1個ずつ」移動する場合の追加1個は対象群へ一度だけ配分することを確定。下表のTX01(A/B)の具体配分はこの確認で補完した。

## 確定した処理

| 発生元・効果 | 合体中の結果 |
| --- | --- |
| 合体スピリットの通常アタック | 相手ライフ減少数+1。元の減少が0なら発生させない |
| BSSA01-X02 反逆者アリス | アタックと疲労時効果のライフ減少へ、それぞれ+1 |
| BSSA01-X01 反逆者キリト | アタック時の除去は最大4個。リザーブ/トラッシュ変更を保持 |
| 夜空の剣自身の記憶開放術 | 相手ライフ減少数+1。既存の発揮条件は維持 |
| BSKB01-TX01(A) | 本体以外の対象スピリット/アルティメットから各1個、追加1個を指定対象のどれかへ配分。自分の対象も配分先に含む |
| BSKB01-TX01(B) Lv3アタック時 | ライフ2個。フィールド・リザーブ各1個に加え、両ゾーンから計1個を追加 |
| 相手フィールド全体から固定数/上限数 | 効果全体の除去可能数+1 |
| 創界神等を明示して除去 | 対象条件を維持したまま固定数+1 |
| 「すべて」の除去 | 存在する全コアを移動。追加コアを作らない |
| 動的個数 | 参照値の確定後に+1。例: BSKB01-M02の先行ライフ減少数、BSSL01-M01の影スピリット数 |
| 回復・ボイドから追加・自分の支払い | 加算対象外 |

不足・耐性・対象条件は従来の共通プリミティブで判定する。各ゾーンに移動可能コアがある限り基本の1個を保持し、残りを任意に配分する。対象/通常・ソウルの選択で中断したときは、確定済みの数を保持して再加算しない。リザーブのソウルコアもそのゾーンの1個として数える。

## 実装上の共通化

- 「このスピリット」の範囲は `isSameCombinedEffectSource` でホスト・合体ブレイヴを照合。下のカード・他スピリットへは拡張しない。
- コア除去とライフ減少の加算照合は別関数。ライフは `core_move`、`life_damage`、アタックの各経路から同じ照合へ合流。
- 複数対象の共有追加は既存 `pendingCoreSourceAllocation` を使用。通常/ソウル選択後の継続には確定個数を保存。
- `from.field.eachZone` は各ゾーンの基本数と共有追加を表す汎用指定。`sourceGroupMinimums` と共通述語で、エンジン・GUI・学習候補の分配を検証する。

## 修剣士キリトのリザーブ／トラッシュ変更（2026-09-12）

- 本文 A: BSSA01-X01 Lv2-Lv3「このスピリットのコアが3個以上のとき、このスピリットの効果の『リザーブ』を『トラッシュ』に変更できる」。本文はリポジトリのカードデータで確認。
- 公式 A: 上記ブレイヴマニュアル page09 は【合体中】効果が合体先に追加されると規定する（2026-09-12 再確認）。
- 適用 C／ユーザー確認: このスピリットのアタック中、効果元がその合体スピリットである効果に限り、コア3個以上ならリザーブへの移動をトラッシュへ変更できる。夜空の剣の記憶開放術のライフ移動も含む。別個体のキリト・他カードの効果へは適用しない。
- 実装: 汎用の移動先変更に任意選択と元の移動先の照合を追加し、既存のステップ選択で解決する。各効果で選び直せる。移動先が元からボイド／トラッシュの効果は変更しない。
- 同時消滅後の順序は [離脱選択](04d_leave-choice-timing.md) に従う。回帰は `kirito-vanish-resolution.test.ts` と `scenario-kirito-vanish.spec.ts`。
