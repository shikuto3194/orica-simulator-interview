# 離脱選択とバースト発動宣言

親章: [状態ベース処理](04_state-based-rules.md)。

### 待機入り・離脱選択・実移動の順序（2026-09-09 確認、信頼度 A）

1. 待機入り時に離脱関連効果を誘発させ、条件を満たすバーストの**発動宣言**を行う。
2. 「離れるとき」「破壊したとき」「消滅したとき」と、それらから派生した効果を解決する。
3. 待機解除・実移動の直前に、契約カードを魂状態にするか、合体スピリット/アルティメットのブレイヴを残すかを選ぶ。
4. 移動先を確定し、同行を選んだブレイヴも同じ離脱処理で移動する。
5. 実移動後に「離れたとき」とその派生効果を解決する。通常のバースト効果はその後（2026-09-22ユーザー再確認、C。通常バーストの待機は[04b の公式Q7734](04b_burst-rules.md)とも整合）。「離れるとき」の待機入りで代用しない。

根拠: 公式エターナル FAQ **Q1501 / Q1533 / Q27659**（選択時点）、**Q420 / Q436 / Q480**（発動宣言時点）。
[公式FAQ（Q480更新日）](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=&update=2026-05-22)。取得記録: `external-qa-official/_freeword-契約カード.md`、`_freeword-バーストの発動を宣言.md`、`CB24.md`。
「宣言前」ではなく「効果解決前」である点はユーザーも公式順に同意（2026-09-09）。魂状態等で破壊後条件が失われた宣言は、Q420 / Q437 に従い元へ戻す。

### 同じ効果から派生する別イベント（2026-09-11）

- 根拠 A: Q1501 は「『フィールドを離れるとき』の効果などをすべて解決して、フィールドを離れるのが確定したとき」に魂状態を選べるとする（外部Q&Aミラー `external-qa-official/_freeword-契約カード.md:108`）。[公式エターナル FAQ Q156](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=&update=2025-02-14) は、「効果発揮後」の前段から派生した効果を解決してから待機カードを移動する順序を示す。
- 適用上の推論 C: 本章と [04 の原因チェーン閉鎖原則](04_state-based-rules.md#フラッシュのタイミング原則) に従い、同じ解決区間のカウント増減・ドロー・状態化等から派生した誘発も解決／辞退してから、魂状態・ブレイヴ残留を選択し、待機解除・実移動する。
- 例: BSGE01-TX01(B) の「カウント-1することで破壊」→ BSGE01-C01 ティアーストーンの誘発解決／辞退 → 被破壊契約カードの魂状態選択。この独自カードの組み合わせを名指す公式Q&Aを確認したという意味ではない。
- 「この効果発揮後」は区間の境界。その前の複数処理と派生誘発を終え、前段の離脱を確定してから後段へ進む。外側の召喚等のコスト支払い待機は、04 例1・例2どおり原因チェーン全体の終了を待つ。
- 実装・再現・前回修正との差分: [2026-09-11 の完了記録](../30_plan/03_completed-milestones-phase-3-5.md#同一効果の派生誘発と離脱確定順序-2026-09-11)。

### 複数体の離脱選択（2026-09-11）

- ルール根拠 A: 公式エターナル Q9284 は「相手によってフィールドを離れるとき」を「相手の効果やバトルで消滅/破壊されたり、手札/手元/デッキに戻るとき」と説明する（`external-qa-official/BS58.md:532-535`）。魂状態の選択時点は上記 Q1501 に従う。
- 適用 C: BSGE01-R01 の本文「相手によってフィールドを離れたこのスピリットは魂状態にできる。」と上記の文言定義から、相打ちした双方がそれぞれ選択する。非契約カードの独自効果への適用であり、同カードを名指す公式裁定ではない。
- 実装上の要件: 表示する選択を1件に絞っても、未選択の適格カードはすべて待機させる。2体破壊・破壊とデッキ下戻しの混在・複数プレイヤー・異なる原因チェーンであっても、各離脱の原因と移動先を保持する。魂状態・煌臨元への追加・ブレイヴ残留に共通する要件。
- 受諾／辞退後は残るカードの選択を再判定し、離脱関連の効果・選択を終えてからバトル終了時へ進む。後続の原因効果・派生効果が解決中なら、既存の待機解除ゲートを尊重する。
### 同時消滅をまとめた誘発と待機解除（2026-09-12）

- 上記 Q1501（A）を適用し、複数体の消滅から1回にまとめた「消滅させたとき」も、全関連個体の離脱選択より先に解決する。
- 実装漏れ: 誘発集約後の代表個体だけを待機解除ゲートが照合し、残りの個体の魂状態選択を先に出していた。公開・非公開・宣言中のゲートで関連個体全体を照合する。
- BSSA01-X01＋夜空の剣は、記憶開放術のライフ移動先選択・移動まで全対象を待機させ、その後に各対象の魂状態を選択する。

### スタック応答後の合体中効果（2026-09-13、信頼度 C / ユーザー確認）

- BSGE01-TR01(B) の転醒/アタック時効果を宣言後、スタック応答で合体先が離脱した場合、ブレイヴを「フィールドに残す」「一緒に移動」のどちらを選んでも【合体中】でなくなるため解決できない。
- 実移動順は[04 の原因チェーン閉鎖原則](04_state-based-rules.md#フラッシュのタイミング原則)「内側のチェーンが先にフラッシュし、外側のチェーンは後からフラッシュする」を適用する。今回の待機はスタック側の効果ツリー内で発生したため、その離脱関連効果・選択・実移動を完了してから外側の元効果へ戻り、合体関係を再検査する。対象選択・カウント-2・破壊へ進めず、宣言による使用回数を取り消す（[03f](03f_stack-failure-and-waiting-cores.md)）。同行時の移動先は[05 の「合体スピリット破壊時のブレイヴ」](05_brave-and-attack-special-cases.md#合体スピリット破壊時のブレイヴ)のとおり。

### 同時破壊からの転醒と派生召喚（2026-10-16、一般則 A／適用 B）

- 公式エターナル [Ver.17.0 改訂「待機状態の統一」](https://www.battlespirits.com/news/2026/rule-manual-eternal17-revised.php) は、誘発する効果を解決してからカードを移動すると定める。補強: [SD17 Q24175](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=SD17) は、破壊で誘発した回収効果の解決時には被破壊カードがまだトラッシュにないとする。
- 上記と本章の派生効果順を BSTH04-転醒R02(A)「太陽の畑」へ適用する。相手の同一効果で他のカードと同時に破壊された場合、転醒した自身は B 面「フィールドに残り」により待機解除する。他の対象は、彼岸の『転醒時』と内包召喚の『召喚時』等の派生効果を解決／辞退するまで破壊待機を保つ。独自カードを名指す公式裁定ではなく一般則からの適用（B）。
- 彼岸が召喚できるのは解決時点ですでにトラッシュにある適格スピリットカード。同時破壊中の対象を先にトラッシュへ移して召喚候補へ加えてはならない。転醒辞退時は離脱反応を終えて全対象を移動する。
- 実装: `state-based-actions.ts` の `trackPendingLeaveResolutionReactions` は、同じ解決区間で発生し、既存の実移動待機判定で有効な pre-flush 反応を、同時離脱の他の対象の `reactionChainIds` にも登録する。実効果を持たない raw 登録や、残留禁止で待つ必要のない自身の反応は除外する。登録済み効果・非公開宣言・付与効果は、それぞれ既存の待機判定を再利用する。既存の宣言・派生チェーン追跡で完了まで待つ。外側の原因チェーン全体は束縛せず、「この効果発揮後」や無関係な後続区間の離脱境界を保つ。
- 再現: `rebirth-simultaneous-leave.test.ts` と `?scenario=rebirth-simultaneous-leave`。萃香で太陽の畑＋導界者2枚、または導界者＋適格スピリットを破壊し、両プレイヤーで転醒受諾／辞退・召喚対象・コア配置・派生終了後の移動を確認する。付与された破壊時ドローの受諾／辞退でも、他の同時破壊対象の待機と終了後の移動を確認する。
- 添付 `orica-snapshot-2026-10-16T14-28-20-916Z.json` は card-44 / card-52 が trash、card-60 が B 面 field。相手の選択情報が省略された表示用状態のため、空の pending 配列だけでは効果完了を証明しない。上記の新規再現で、転醒宣言前に他の対象が移動する不具合を別途確認した。
