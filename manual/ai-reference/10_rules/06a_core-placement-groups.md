# 系統などの共有枠を持つコア配置

## BSTH11-R03（2026-09-26ユーザー確認、信頼度C・実装採用）

「各系統1個ずつまで」の対象は、自分のスピリット/アルティメット/創界神ネクサスを横断する。
配置先ごとに最大1個、指定された各系統について全配置先で共有して最大1個。
複数系統を持つカードにも2個以上は置けない。既存の系統別6ステップから同じカードを再選択する処理は、この制約を満たさない。

配置したカードと指定系統を、重複しないよう対応付けられる配分だけを認める。
どの系統として置くかはユーザーに選ばせず、確定前の全配置に対して対応の存在を判定する。
例えばA=幻想/秘神、B=幻想なら、A・Bに1個ずつ置ける。A=秘神、B=幻想として成立する。
「まで」なので最大数まで置く義務はなく、0個でも後段へ進める。

ユーザーの判断は「コア配置」「未契約ならトラッシュ3コアをボイドに置いて2枚ドロー」の2段階。
配置は1回のHUDにまとめ、合法な追加先だけを黄色枠で示す。配置済みカードは候補から外す。
完了前はリセットして選び直せる。
後段の順序と支払いは [効果文の解釈](03c_effect-text-interpretation.md) の「その後」「ことで」に従う。

## 共通実装

- `core_distribute(mode:"player_choice")` の `maxPerCandidate` と `allocationGroups` で表す。
- 各共有枠は `CardFilter` と上限。共通TargetSpec解決で実効系統などを評価し、配分候補との共通部分を保持する。
- 最大配置数・仮配置・確定・AI候補は `core-distribution-constraints.ts` を共有し、既存の配分最大流を利用する。
- BSLH01-X04「CBスピリット4体までに1個ずつ」にも、配置先上限と1回のHUDを適用する。
- 固定対象すべてへの自動配置や、コアを取り除く効果は、選択・実行の意味が異なるため一括置換しない。
