# フラッシュ/スタックの見出しラベルと本文の実行窓

(独自カード裁定、信頼度 C、2026-06-16 ユーザー確認。BSLH01-X04 クォーツ・BSFT01-CX01 星霊衣ほか)

見出しラベルと本文の実行窓を区別する。

- **見出しラベル位置の「フラッシュ」＝フラッシュ効果**。単独見出し「フラッシュ」や「フラッシュ 煌臨/【チェンジ：…】/【アクセル：…】」のキーワード前置ラベル。フラッシュ見出しの個体のみ該当。
- 常時効果による召喚許可は即時効果と別。本文で「フラッシュタイミングに召喚できる」とするカードは「フラッシュ効果ではありません」とされ `restrict_flash` では止まらない（BS53:756-757 / BS61:51-52 / CB16:700-703、信頼度 A）。同型の手札/手元からの配置 permission も行為許可扱い。一方、《契約煌臨》を「使用して発揮」するものは止まる（BS62:449-452 / BS63:545-548）。
- **本文中の「フラッシュタイミングで」＝フラッシュ効果ではない**。別カテゴリの行為（クォーツ起動 / アンダーカード入替 / 裏返し / 魂状態セット / 創界神起動 / キーワード効果 など）が、その**実行可能窓**としてフラッシュタイミングを使っているだけ。
- スタックも同様。スタック見出しを持たず本文の「スタックタイミングで」によって行える効果は、スタック効果ではない。BSAZ02-TX01(A)【転醒】はこの分類で、太陽の畑の「スタック効果を発揮できない」では禁止されない（2026-09-21 ユーザー確認、信頼度C）。
- 「フラッシュ/スタック」の両ラベルを持つ効果は、今回発揮するタイミングで分類する。BSTH11-X01の神技をスタックとして発揮する場合はスタック禁止の判定対象だが、通常フラッシュでの発揮にはスタック禁止を適用しない（2026-09-21 ユーザー確認、信頼度C）。[太陽の畑・星霊王との具体例](03e_first-attack-continuous-restrictions.md#創界神の神技とプレイヤー対象禁止)。
- 用途: 「フラッシュ効果使用後以外」条件（`flash_used`）の計数、pay-to-act ゲート（本ファイル §「○○しなければ△△を発揮できない」）の対象 — **見出しラベルのフラッシュ/スタック効果のみ**を数える。

[R01/CX01〜CX04 と両ゲートの具体例](03d_effect-target-and-prerequisite-gates.md#効果種別の具体例2026-09-10再確認)。

実装: `timing.mode` は実行窓、効果カテゴリは `Effect.activationLabel` で判定。本文窓の行動は `activationLabel:"none"` とし、`flash_used` / `gate_flash_stack_core` / `restrict_flash` / `restrict_stack` の対象から除外する。窓の発生元そのものの抑止（`suppress_stack_source`）とは区別する。

## 非効果の型ラベル

`【タイプ：歌】`（派生表記の `【タイプ：歌／…】` を含む）は、それ自体では効果を発揮しない分類ラベルである。本文が参照または対象にするときだけ属性として働くため、効果本文・起動見出し・実行窓として扱わない。公式 Q26223（`external-qa-official/BSC35.md:544-545`）を正源とする。
