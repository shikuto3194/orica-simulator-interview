# カード効果の対象分類監査

2026-11-08。対象は card-data/src/cards の全39ファイル。TypeScript の構文木に加え、生成済みカード一覧594件から裏面・派生効果を含めて1,873件の効果を列挙した。カード本文全体の人称直後の読点、各効果の textRef、DSL の action、プレイヤー耐性を照会する実行経路を照合した。複数の処理が同じ textRef を共有する場合は、該当する節だけで対象を判定した。選択者・所有者・コスト支払い元にプレイヤーが書かれていても、それだけでは対象種別を決めない。

- 読点規則の正源は [対象と発揮前提](03d_effect-target-and-prerequisite-gates.md)。独自 Q&A qa-024・qa-025 の具体例を比較した。公式エターナルの手札保護との類例は [BS57のQ&A](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=BS57) にある。
- BSSG01-C07 と BSTH02.7-TR02(A) のスタック制限、BSTH04.5-X01 と BSTH05-X04 のフラッシュ制限、BSES01-CX01 等の終了制限は発揮元に作用する。星霊王のスタック・煌臨制限と BSTH003-X03 の終了制限はプレイヤーに作用する。
- BSTH02-M02 と BSTH08.5-M11 のバースト発動制限はバーストの発揮元、BSTH004-X03 の転醒制限は破壊される効果発揮元、BSTH07.8-C03 の軽減無効は配置するカード、BSTH08-C06 と BSTH03-M04 の支払い元制限はスタック効果の発揮元に作用する。BSSL01-R03 はリザーブが対象。BSTH08.5-C20 は手元のシンボル供給カードが対象。
- 読点付きの破棄、対象不可、支払い・発揮の条件、ライフとコアの制限、ブロック数上限では、本文で指されたプレイヤーに耐性を照合する。カードやコアへの個別処理の耐性判定もそれぞれの経路で行う。
- 対象によって処理が分岐する使用制限・タイミング制限等は DSL で targetScope を必須にした。プレイヤー耐性を適用するのは明示の player または playerTarget がある経路。生成済みカード一覧で明示必須の43アクションに対象指定があり、明示のプレイヤー対象35アクションに対応する本文の読点があることを照合した。古い保存済みの継続効果には対象の情報がない場合があるため、既存の消費規約を使う。

「相手は、この効果を2体以上防げない」等の BSTH04.5-X01・BSTH05-C11・BSTH05-C12 は、通常処理の対象カードとは別に、相手プレイヤーに防止数の上限を課す文言。対象確定後、通常の「防げない」で貫通できる耐性により2体以上が防げるときは、防御側がそのうち1体を選び、残りには耐性を貫通して疲労または手札戻しを適用する。防げる対象が1体以下なら、そのまま耐性を適用する。対象取得禁止やルール上の不可には、通常の対象取得・解決規則を適用する。リポジトリに収録した公開Q&A・エラッタには防止先の選択者を明示する項目が見当たらず、防御側が選ぶ点は2026-11-08のユーザー裁定。
