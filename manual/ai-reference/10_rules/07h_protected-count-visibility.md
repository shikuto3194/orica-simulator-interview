# 保護カウントの可視範囲

BSGE01-C13 等の「追加したカウントは自分の系統：「神喰」を持たない効果で数えられず、その効果を受けない」で保護されたカウント（以下、保護分）が、どの参照・支払いから見えるかの裁定。クォーツの基本定義は [07 §4](07_custom-orica-mechanics.md#4-クォーツ)。

## 裁定

| 対象 | 保護分 | 出典・信頼度 |
|---|---|---|
| クォーツコストの支払い | 使える（効果ではない支払いコスト） | 独自サイトQ&A `qa-039`（2026-08-10）／A |
| 系統「神喰」を持たない発揮元が「数える」参照（転醒の条件・OC・石転醒・`usageLimit` の `count_value`） | 除く | ユーザー裁定で確定（2026-11-01）。根拠はカード文面からの推論／C |
| 契約創界神のLv、ブレイヴ条件 | 総量のまま | 未整合の可能性あり。該当カードで差が出たら再確認する |

## 実装

- 正源は `model.ts` の `countValueVisibleToEffect`。発揮元の系統で保護分を除く。
- 公式Q&Aが直接示すのはクォーツコストだけで、転醒・OCへの適用は推論。個別カードで公式裁定が出たら本表を更新する。
