# 無償使用の制限

公式エターナル [Q2056・Q2057](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=BS04) は、軽減で0になったマジックを使用できることと、支払いを省略する効果での使用を禁止できることを区別する（信頼度A、類例）。

BSTH08.5-C22「能面・猿（困）」は、手元にある間、両プレイヤーが手札・手元のカードを無償で使用する経路を制限する。印字コスト0、軽減後0、固定支払い0、コストを0に変更した使用は許可する（2026-11-08 ユーザー確認 C、実装に使用）。独自カード本文は [カードデータ](../../../packages/card-data/src/cards/BSTH08.5.ts) と独自サイトのミラーに収録。独自 qa-042 は同カードのアクセル再発揮を扱う。

- C22 の「お互い」に読点がなく、手札・手元のカードが対象。C22 に対して有効な手札保護・手元保護があれば、そのカードを無償で使用できる（2026-11-08 ユーザー確認 C、実装に使用）。[人称判定](03d_effect-target-and-prerequisite-gates.md#効果の対象がプレイヤーかカードゾーンか人称判定)に従い、カードの耐性は使用前のゾーンで判定する。
- DSL の restrict_use.onlyWithoutCost は、使用経路が支払いを省略するかを照合する。余分コストが残る無償経路にも適用する。
- 召喚の free / withoutCost と fixedPayment / override を区別する。継続の cost_modify は無償付与を free、0への変更を override:0 で表す。BSTH08.5-R12 の「コストすべてを0にできる」も後者。
- 同類監査では、カードデータの禁止文言と0コスト指定を照合し、エンジン側の効果召喚・配置、マジック（誘発・ライフ減少割り込みを含む）、アクセル、効果によるミラージュ・クォーツセットの使用経路を確認した。別の固定額・余分コスト・コスト下限制限はそれぞれの条件に従う。
