# 煌臨のソウルコア支払いと対象の存続

親索引: [煌臨 / 転醒 / 契約](08a_advent-rebirth-contract.md#1-煌臨advent)。

- 煌臨先の最後のソウルコアを実際に支払って消滅させる場合は煌臨不可。「置いたものとして」なら実移動しないため、ソウルコアだけの対象にも煌臨でき、そのコアを引き継ぐ（2026-09-10確認）。
  - 根拠 **信頼度A**: [公式エターナル版 Q17101](https://www.battlespirits.com/faq/list.php?prodname=SD51&format=eternal) / `external-qa-official/SD51.md:14`「この効果はソウルコアをトラッシュに置いたものとして、トラッシュに送らずに《煌臨》する効果です。」ソウルコア単独対象への適用はこの非移動と状態引き継ぎからの推論（ユーザー確認一致）。
  - 実装: `canAdventTargetSurvivePayment` を候補列挙・解決で共有し、通常/契約/F契約煌臨と【真バディ】の各支払い経路に適用。宣言候補は合法な経路の和集合、スタック窓後は選択した経路で再評価する。

- 常時型「置いたもの」の宣言・使用回数・全11枚監査は [常時の許可と宣言](08a5_as-if-soul-core-permissions.md)。
