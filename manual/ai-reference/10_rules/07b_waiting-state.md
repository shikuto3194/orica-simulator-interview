# Waiting State（待機状態）

親: [カード本文から観測できた独自/確定ギミック](07b_card-observed-mechanics.md)。

`待機状態` は、フィールド離脱確定後・実移動前の途中状態である。

- 破壊 / 消滅 / バウンスなどでフィールドから離れることになったカードが入る。
- `破壊の待機状態` / `消滅の待機状態` / `バウンスの待機状態` のように種類が分かれる。
- `手札に戻す。この効果で戻した〜` 型では、「戻した〜」以降を手札に戻す待機状態で解決する。

## 効果制限

**待機状態になったカードは、待機状態に関係する効果以外を発揮できない。**

公式 Q2404 は「待機状態になったスピリットは、待機状態に関係する効果以外の効果を発揮できなくなります」とする。最新確認の Q31800 も、消滅させながら別スピリットを召喚し、その召喚時効果でドローしても、消滅待機中の元スピリットの2つ目の効果は発揮できないと明示する。したがって、離脱に無関係な「別カードが召喚/配置したとき」等の誘発は、待機状態の発揮元からは不発である。

「フィールドを離れるとき」や「フィールドに残る」など、待機状態自体を扱う効果は例外として発揮・適用できる。

根拠（信頼度 A）:

- 公式 Q2404（`external-qa-official/BS07.md:391-394`、2026-04-03）
- [公式 Q31800](https://www.battlespirits.com/faq/list.php?format=eternal&prodname=&update=2026-08-07)（2026-08-07）

## 実装含意

- `pendingLeaveKind` / `flushPendingLeaves()` は、公式待機状態の実装として扱う。
- `pendingLeaveKind !== null` の発揮元は、待機状態に関係しない triggered registration を候補・解決の両方で除外する。
- 登録済み誘発の候補列挙とスタック解決は `canTriggerFromPendingLeaveSource()` を共用する。自身の現在の離脱種別に対応するイベントだけを許し、耐性で離脱を阻止したマーカーは待機状態に含めない。
- 2026-09-22 のリムル保存状態は `card-1`（消滅待機）が `card-6`（トラッシュから召喚）の召喚に誤反応したもの。回帰: `pending-leave-trigger-source.test.ts` / `no-duplicate-queue.test.ts` / `?scenario=rimuru-pending-leave`。旧スタックもカウントを増やさず解決を終える。
