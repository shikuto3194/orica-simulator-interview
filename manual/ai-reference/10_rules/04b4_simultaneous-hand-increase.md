# 同時手札増加とバースト

親章: [バースト関連ルール](04b_burst-rules.md)。2026-09-19 調査。

## 公式根拠（信頼度 A / 実装要件に採用）

- **Q484**（2024-10-31）: オープン元の効果で1枚、オープンされたカード自身の効果で1枚を手札に加えた例について、バーストが参照する増加枚数は2枚ではなく1枚と回答する。原文抜粋: 「バーストは発動を宣言するとき、発動する条件の事象が複数ある場合、その中で対象を1つ指定する」。同時に増えても原因効果は別々であり、宣言時にどちらを条件事象とするか指定する。
- **Q7927**（2024-10-31）: 同型のオープン回収について、原文抜粋: 「別の効果でも同じタイミングで手札に加えることになる」。オープンされたカードの自己回収とオープン元の回収は、逐次の別タイミングではない。
- **Q440**（2026-04-03）: 手札増加後バーストの宣言は、その手札増加から誘発する手札効果の提示と同じタイミング。

取得先: [公式エターナル FAQ・手札が増え](https://www.battlespirits.com/faq/list.php?freeword=%E6%89%8B%E6%9C%AD%E3%81%8C%E5%A2%97%E3%81%88&format=eternal)、[BS50](https://www.battlespirits.com/faq/list.php?prodname=BS50&format=eternal)。2026-09-19 に公式から再取得。原文ミラー: `external-qa-official/_freeword-手札が増え.md:6-34`、`external-qa-official/BS50.md:196-199`。

## 今回への適用と実装方針（信頼度 C / 上記裁定からの適用）

ソルティリーナ・セルルト（BSSA01-R01）が8枚オープンし、彗星「ブレイジングスター」（BSTH01-C21）が自身の効果で1枚、ソルティリーナの効果で夜錆3枚を回収する場合:

- **同時に起きた2つの条件事象を保持し、バースト宣言は共通のタイミングで受け付ける。** 同じバーストカードを原因ごとに二重発動させない。同一タイミングの辞退を、別の原因を口実に再提示しない。
- 宣言するバーストが参照する原因は、ブレイジングスターの1枚増加かソルティリーナの3枚増加のいずれか。単一の「4枚増加した効果」に変換しない。原因効果の属性・発揮元も保持する。
- 別々の効果解決で後から新しく手札が増える場合まで、同じチェーンという理由だけでまとめない。手札発動などによる別カードの同時バーストも、この整理だけで禁止しない。

## スナップショットと実装差分

調査対象: `orica-snapshot-2026-09-18T17-38-40-756Z.json`。
公開履歴19でブレイジングスター1枚、20でソルティリーナの選択3枚が手札へ移動。
`pendingBurstChecks` は同じ `deck-reveal:dr-1` に amount 1 / 3 の2件、両方 `activationSelected:false`。
セット中カードは `card-8`（BSTS01-R02 ソウエイ）。この保存状態が証明するのは確認キュー2件であり、効果本体の二重解決完了ではない。

実装調査:

- `packages/rules-core/src/legal/pending-action-handlers.ts:908` の `applyPendingDeckRevealAction` は途中の選択操作ごとに差分を確定し、同じオープンIDで `finalizeEffectResolution` を呼ぶ。
- `packages/rules-core/src/effect/trigger-system.ts:5096` 付近で操作差分ごとの手札増加を生成し、`createPendingBurstCheckId`（2068付近）/ `buildBurstCheck`（6656付近）で個別チェックを作る。スナップショットでは自己回収側も `relatedInstanceId:card-55`（ソルティリーナ）になっている。
- 修正要件: 同時に加わる回収の宣言タイミングを共有し、原因・増加枚数の候補を保持する。宣言時に条件事象を選び、辞退・宣言済みカードの扱いを同じタイミングで統一する。単純な amount 合算や chainId 全体の重複除去は不可。

2026-09-19: 全バーストの原因表示と、オープン／トラッシュからの任意・強制自己回収の発揮元を修正。手札移動記録に効果元を残し、外側の効果で上書きせず原因別に集計する。公開済みの自己回収カード名は手札へ移っても保持する。上記 snapshot の保存済み誤帰属は履歴から推測修復しないため、修正後の同じ操作で再生成する。

2026-09-19 追補: 発動選択時に、宣言したカードだけが候補の他チェックを即時消費する。宣言済みカードは他原因から再宣言できない。選んだ原因・枚数、別カードの手札バースト、相手側の確認は維持する。現在の候補集合だけを整理し、同じchainの後続事象をまとめて除去しない。

「発動しない」は原因ごとの辞退を維持。同時タイミング全体の辞退単位は root `needs-ruling.jsonl` の `simultaneous-open-hand-increase-burst` と [P3-162](../../../issues/P3-162_simultaneous-burst-causes.md) に残す。
