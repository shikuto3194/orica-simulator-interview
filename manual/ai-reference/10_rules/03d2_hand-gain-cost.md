# 手札増加に対する「支払わなければ」の対価

親: [効果対象・発揮前提](03d_effect-target-and-prerequisite-gates.md)。
根拠: [2026-09-21調査](../00_meta/source-findings-hand-gain-cost-2026-09-21.md)。

## 支払いの任意性と禁止の優先

信頼度 C（独自カード本文・2026-09-21ユーザー裁定）。一般の禁止優先は
[03c](03c_effect-text-interpretation.md)の「『できない』＞『しなければならない』＞『する・できる』」。

- BSRK01-C02「神谷 薫」の対価は支払わないことも選べる。回収本文が「手札に加える」という強制文でも支払いを強制しない。
- 未払いなら、そのイベントの手札増加が禁止される。BSTH04-C01「[花映塚]チルノ」は公開後の回収2枠をともに抑止し、全公開札を「残ったカード」として破棄する。公開自体は取り消さない。
- コスト源は通常の支払いと同じリザーブ/フィールドの使用可能コア。通常コア/ソウルコアと支払い元を選ぶ。

## イベントの単位

- 「増加/回収枚数を+1する」は元イベントの枚数を加算する。別の手札増加イベントを作らず、対価も増やさない（同日ユーザー追補）。BSAZ01-C01の合体中ドロー+1も合計2枚で1回。

- チルノ本文の「導界者ネクサス1枚と、幻想・起幻のカード1枚」は同じ手札増加イベント。2枠合わせて1コストを1回支払う。支払い後は可能な限り強制回収する。
- 「オープンされた/トラッシュに置かれたこのカード」をそのカード自身の効果で回収する場合は効果元が異なる。元の公開/破棄効果による回収とは別イベントで、支払い・拒否を共有しない。複数の自己回収もそれぞれ別イベント。
- 効果によるドローもデッキからの手札増加である。BSTH04-C12「投銭『宵越しの銭』」の2枚ドローには1コストを1回要求し、拒否するとデッキを動かさずドローだけを抑止する。後続の独立した処理は継続する。
- 通常のドローステップのルールドローは「相手の効果」による増加ではなく対象外。相手の効果で引かされる場合も「そのプレイヤー自身の効果」の条件を満たさない。

## 実装と回帰

- 対象判定・支払元列挙・支払検証の正源は `effect/hand-gain-cost.ts`。`hand_gain_cost_gate` の直接参照を各ハンドラで再実装しない。プレイヤー対象の制約であり、回収効果元が創界石等でも免除しない。プレイヤー自身の対相手効果耐性は適用する。
- `move_card` / `search_zone`（デッキ・トラッシュ・混合検索）も、実際の移動元がデッキ・トラッシュ・公開領域で移動先が手札なら対価を要求する。手元・除外からの移動、交換、他プレイヤーの効果による回収はこの対象外。
- 浄玻璃の鏡は配置時の任意発揮→2枚破棄→回収の任意発揮→対象選択→コアHUD。0コアでもHUDを出し、空配分/支払拒否では対象をトラッシュに残す。再開時は選択した対象を保持し、破棄を再実行しない。
- リザーブ・通常フィールド・ソウルコアの支払いを共通コスト検証へ渡す。拒否は回収成功や対象参照として後続へ渡さず、別の回収stepへ支払いを流用しない。公開後二択の本文コストと外部回収対価は別の支払い。
- 公開回収は `PendingDeckReveal.handGainCostDecision` で本文内の支払い/拒否を保持する。カード自身の `revealed_choice` は個別イベントとして計算し、新しいトラッシュ回収pendingにも引き継がない。
- 効果ドローはドロー直前にコア配分pendingを作り、`canDecline` による空配分で抑止する。支払い後に同じstepを再開し、別stepのドローには配分を流用しない。
- GUIは回収選択後にコストHUDを開き、元の選択には「支払わず回収しない」を表示する。ドローHUDにも支払い拒否を表示する。REST/AIも同じ合法アクションと支払い元検証を使う。
- 回帰: `deck-reveal-hand-gain-event.test.ts` / `hand-gain-cost-zone-moves.test.ts` / `reveal-then-choose-retrieval.test.ts`。GUI/REST: `scenario-hand-gain-cost.spec.ts`、`?scenario=hand-gain-cost`（`mode=draw/mirror/zone` / `cores=zero/field` / `owner=bob`）。
